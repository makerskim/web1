# 🌱 쑥쑥 앨범 — 멀리 있는 가족과 함께 보는 아기 사진 앨범

할머니·할아버지도 쉽게 쓸 수 있는, 인스타그램처럼 보기 편한 **우리 가족 전용** 아기 사진 앱이에요.

- 📷 사진 올리기 (한 번에 10장까지) + **꾸미기**: 필터 9종, 스티커, 글씨(손글씨·동글체), 테두리(폴라로이드·하트·필름 등), 날짜 도장, 자르기·돌리기
- 👶 사진마다 **‘생후 123일’**, 백일·첫 돌 같은 특별한 날 자동 표시
- ❤️ 두 번 톡톡 좋아요, 💬 **한 번 누르면 바로 남겨지는 빠른 댓글** (“😍 너무 예뻐요”, “🥰 보고 싶다”…)
- 🔔 ‘소식’ 탭: 누가 좋아요·댓글을 남겼는지
- 🖼️ ‘모아보기’: 달마다 정리된 성장 앨범, 크게 보기(두 손가락 확대)
- 🔠 글자 크기 3단계 (보통 / 크게 / 아주 크게)
- 📲 홈 화면에 설치하면 앱처럼 아이콘으로 열기 (안드로이드·아이폰 모두)
- 💾 한 번 본 사진은 **휴대폰 안에 보관** → 다음부터 바로 열리고, 인터넷이 약해도 보여요.
- 📥 **원본 그대로 내려받기**: 올릴 때 원본 파일도 같이 올라가서, 가족 누구나 ‘저장’ 버튼으로 **화질 손실 없는 원본**을 휴대폰 사진첩에 받을 수 있어요. (꾸민 사진이면 ‘원본 / 꾸민 사진’ 중에 골라요)
- ⭕ 위쪽 동그라미(스토리)로 최근 3일 동안 올라온 사진을 넘겨 보며 이모지로 바로 반응
- 🔒 초대 링크를 받은 가족만 볼 수 있어요. (낯선 사람은 사진·앨범을 볼 수 없게 데이터베이스에서 막아 두었어요)

## 왜 ‘앱스토어 앱’이 아니라 ‘웹앱’인가요?

| | 웹앱 (이 방식) | 플레이스토어 | 앱스토어(아이폰) |
|---|---|---|---|
| 비용 | **0원** | 등록비 25달러(1회) | **매년 99달러** + 맥 컴퓨터 필요 |
| 심사 | 없음 | 있음 | 있음 (가족 전용 앱은 거절되기 쉬움) |
| 설치 | 링크 누르고 ‘홈 화면에 추가’ | 스토어에서 설치 | 스토어에서 설치 |
| 고치기 | 파일만 바꾸면 바로 반영 | 다시 심사 | 다시 심사 |

가족끼리만 쓰는 앱이라면 웹앱이 가장 싸고 빠릅니다. 홈 화면에 설치하면 겉모습도 일반 앱과 거의 같아요.
(나중에 꼭 플레이스토어에 올리고 싶으면 [PWABuilder](https://www.pwabuilder.com)로 이 웹앱을 안드로이드 앱으로 포장할 수 있어요.)

> 💡 “사진을 휴대폰에만 저장”하면 멀리 계신 부모님 휴대폰으로 사진이 갈 수가 없어요.
> 그래서 **무료 클라우드(Supabase)** 를 ‘우체국’처럼 써서 사진을 전달하고, 받은 사진은 각자의 휴대폰에도 보관해요.
> 화면에는 빨리 열리도록 줄인 사진(긴 쪽 1440px, 인스타그램보다 선명)을 보여 주고, **원본 파일은 따로 보관**해서 ‘저장’할 때만 내려받아요.

## 1단계 · 일단 열어 보기 (체험 모드, 5분)

설정 없이도 바로 열려요. 이때는 **체험 모드**라서 사진이 그 기기에만 저장되고 가족과 공유되지 않아요.

1. GitHub에서 이 저장소(`web1`) → **Settings → Pages**
2. *Build and deployment* 의 **Source: Deploy from a branch**, **Branch: `master` / `(root)`** → Save
   (이 코드를 아직 `master`에 합치지 않았다면 먼저 합쳐 주세요)
3. 1~2분 뒤 휴대폰에서 열기: **https://makerskim.github.io/web1/album/**

## 2단계 · 가족과 공유하기 (무료 Supabase 연결, 15분)

### ① Supabase 프로젝트 만들기
1. [supabase.com](https://supabase.com) → **Start your project** → GitHub 계정으로 로그인
2. **New project**
   - Name: `ssukssuk` (아무거나)
   - Database Password: 아무거나 (메모해 두세요)
   - Region: **Northeast Asia (Seoul)** ← 한국에서 빠름
   - Plan: **Free**
3. 1~2분 기다리면 프로젝트가 만들어져요.

### ② 데이터베이스 설정 붙여넣기
1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. 이 폴더의 [`supabase/schema.sql`](supabase/schema.sql) 내용을 **전부 복사해서 붙여넣기** → **Run**
3. 아래쪽에 `Success. No rows returned` 가 나오면 성공 (여러 번 실행해도 괜찮아요)

### ③ ‘익명 로그인’ 켜기
할머니·할아버지가 **아이디·비밀번호 없이** 초대 링크만으로 들어오게 해 주는 설정이에요.

1. 왼쪽 메뉴 **Authentication → Sign In / Providers** (화면에 따라 *Providers* 또는 *Settings*)
2. **Allow anonymous sign-ins** 를 켜고 **Save**

### ④ 앱에 주소와 키 넣기
1. Supabase 왼쪽 아래 **Project Settings** → **API Keys** (또는 *Data API*)
   - **Project URL**: `https://abcdefgh.supabase.co` 같은 주소
   - **Publishable key** (`sb_publishable_…`) — 예전 프로젝트는 **anon public** 키 (`eyJ…`)
   - ⚠️ `secret` / `service_role` 키는 **절대** 넣지 마세요!
2. GitHub에서 [`album/config.js`](config.js) 를 열고 ✏️(연필) 버튼 → 두 값을 붙여넣기:
   ```js
   export default {
     supabaseUrl: 'https://abcdefgh.supabase.co',
     supabaseKey: 'sb_publishable_xxxxxxxxxxxx',
   };
   ```
3. **Commit changes** → 1~2분 뒤 앱을 새로 고침

> Publishable(anon) 키는 원래 공개되어도 되는 키예요. 실제 보안은 ②에서 넣은 데이터베이스 규칙이 지켜요.

> 🔄 **앱을 새 버전으로 바꿨다면** ②의 `schema.sql`을 **한 번 더 실행**해 주세요. (원본 사진 30MB·아이폰 HEIC 허용, 새 보안 규칙이 들어가요. 여러 번 실행해도 데이터는 그대로예요)

### ⑤ 앨범 만들고 가족 초대하기
1. 앱에서 **새 가족 앨범 만들기** → 아기 이름, 생일, “나는 아기의 [엄마]” 고르기
2. **초대 링크 보내기** → 카카오톡 가족 대화방에 보내기
3. 부모님은 링크를 누르고 **[할머니]** 같은 버튼만 누르면 끝!

> 🔒 맨 처음 앨범 하나는 누구나 만들 수 있지만, 그다음부터는 **이미 가족 앨범에 들어와 있는 사람만** 새 앨범을 만들 수 있어요.
> 그래서 설정을 마치면 **바로 엄마·아빠가 첫 앨범을 만들어** 주세요.
>
> 👋 관리자가 가족을 **앨범에서 내보내면 초대 링크가 자동으로 새로 바뀌어요.** (예전 링크로 다시 못 들어오게) 아직 안 들어온 가족에게는 새 링크를 보내 주세요.

## 홈 화면에 설치하기
- **안드로이드(크롬/삼성 인터넷)**: 앱의 **가족 → ⚙ 설정 → 홈 화면에 앱 설치하기**, 또는 브라우저 메뉴(⋮) → *홈 화면에 추가*
- **아이폰(사파리)**: 아래쪽 **공유 버튼(□↑) → 홈 화면에 추가 → 추가**
  - 아이폰은 홈 화면 앱이 사파리와 따로 저장공간을 써서, 설치한 앱을 처음 열 때 **초대 코드를 한 번 더** 입력해야 할 수 있어요. (가족 → 가족 초대하기에서 8자리 코드 확인)
- 카카오톡 안에서 링크를 열면 휴대폰 기본 브라우저로 넘어가도록 해 두었어요. (카톡 안에서는 사진 저장·설치가 잘 안 돼서)

## (선택) 계정 지키기 — 휴대폰을 바꿔도 다시 들어오기

앨범을 만든 엄마·아빠는 **가족 → ⚙ 설정 → 계정 지키기** 에서 이메일을 연결해 두는 걸 권해요.
(관리자 권한은 그 휴대폰에 묶여 있어서, 휴대폰을 바꾸면 잃을 수 있어요. 앱에서 다른 가족을 **관리자로 지정**해 두는 것도 좋은 방법이에요.)

이 기능을 쓰려면 Supabase에서 한 번만 설정해 주세요.
1. **Authentication → URL Configuration → Site URL** 에 `https://makerskim.github.io/web1/album/`
2. **Authentication → Emails → Templates** 에서 **Magic Link** 와 **Change Email Address** 템플릿 본문에 아래 한 줄 추가:
   ```html
   <p>쑥쑥 앨범 인증번호: <strong>{{ .Token }}</strong></p>
   ```
   (앱에 6자리 숫자를 입력하는 방식이라 아이폰 홈 화면 앱에서도 잘 돼요)
3. ⚠️ Supabase 무료 기본 메일은 **Supabase에 가입한 본인 이메일(과 팀원)** 에게만 보내져요. 그래서 이메일 연결은 Supabase 프로젝트를 만든 사람만 쓸 수 있어요.
   다른 가족에게도 쓰게 하려면 **Authentication → Emails → SMTP Settings** 에 Gmail·Resend 같은 메일 서비스를 연결해야 해요. 그게 번거로우면 다른 가족을 **관리자로 지정**해 두는 것으로 충분해요.

## 무료로 얼마나 쓸 수 있나요?

Supabase 무료 플랜 기준 (정확한 최신 한도는 [supabase.com/pricing](https://supabase.com/pricing)에서 확인):

- 파일 저장 **1GB**
  - **원본도 함께 올리면** (기본값): 휴대폰 사진 원본이 한 장에 보통 2~5MB라서 **약 250~400장**
  - **원본 없이 올리면**: 한 장에 약 250~350KB라서 **대략 3,000장 이상**
  - 사진 올리기 마지막 화면의 **‘원본 화질로도 올리기’** 스위치로 고를 수 있어요. (한 번 고르면 다음에도 그대로)
- 공간 관리: **가족 → 오른쪽 위 ⚙ 설정 → 저장공간** 에서 얼마나 찼는지 보여요. 80%가 넘으면 관리자에게 알려 줘요.
  - **오래된 원본 정리**(관리자만): 3개월·6개월·1년 지난 사진의 원본만 지워요. 화면용 사진·꾸민 사진·좋아요·댓글은 그대로 남아요. 지우기 전에 원본을 휴대폰에 저장해 두세요.
- 각 휴대폰은 사진을 한 번만 받아서 보관하므로 데이터 전송량은 거의 문제가 안 돼요. (원본은 ‘저장’을 누를 때만 받아요)
- ⚠️ **7일 동안 아무도 앱을 쓰지 않으면** 프로젝트가 잠시 멈춰요. 데이터는 그대로 있고, Supabase 대시보드에서 **Restore** 를 누르면 다시 켜져요. (매주 사진을 올리는 가족이라면 걱정 안 하셔도 돼요)
- 꽉 차면: 오래된 원본을 정리하거나, 유료 **Pro 플랜(월 25달러, 저장 100GB)** 으로 바꾸면 원본을 수만 장 보관할 수 있어요.
  Pro로 바꿨다면 `config.js`의 `storageLimitGB: 1` 을 `100` 으로 고쳐 주세요. (저장공간 막대가 맞게 보여요)

## 사진 백업
- 원본을 같이 올렸다면 가족 누구나 게시물의 **저장** 버튼(또는 ⋯ → 저장)으로 **원본 그대로** 받을 수 있어요. 파일 크기·화질·촬영 정보가 처음 찍은 사진과 똑같아요.
  - 원본은 **꾸미기 전** 사진이라, 자르거나 스티커로 가린 부분도 원본에는 그대로 보여요.
  - 촬영 정보에 **찍은 장소(GPS)** 가 들어 있을 수 있어요. 아이폰·최근 안드로이드는 사진을 고를 때 보통 위치를 빼 주지만, 걱정되면 카메라 설정에서 ‘위치 태그’를 끄거나 그 사진은 원본 스위치를 끄고 올려 주세요.
- 아이폰은 ‘저장’을 누르면 공유 창이 열려요 → **‘이미지 저장’** 을 눌러 주세요.
- 안드로이드에서 사진 여러 장을 저장할 때는 첫 장이 바로 저장되고, **[다음 사진 저장]** 버튼을 누를 때마다 한 장씩 저장돼요. (크롬이 한 번에 여러 파일 받는 것을 막아서)
- 아이폰에서 사진을 올리면 사파리가 HEIC 사진을 **해상도 그대로의 고화질 JPG** 로 바꿔서 앱에 넘겨줘요. 그래서 아이폰 원본은 JPG로 저장돼요. (누구 휴대폰에서나 잘 열려요)
- 카카오톡 안에서 연 화면에서는 저장이 안 돼요. ‘브라우저로 열기’ 안내가 나오면 따라 주세요.
- 그래도 앱은 ‘전달용’이라고 생각하고, **원본은 엄마·아빠 휴대폰(또는 구글 포토·아이클라우드 등)에도 꼭 보관**해 주세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| “데이터베이스 설정(schema.sql)이 아직 안 되어 있어요” | 2단계 ② 다시 실행 |
| “Anonymous sign-ins(익명 로그인)를 켜 주세요” | 2단계 ③ |
| 사진을 올릴 때 “사진 정보가 올바르지 않아요” | 앱 파일만 바꾸고 `schema.sql`을 다시 실행하지 않았을 수 있어요. 2단계 ② 다시 실행 |
| “새 앨범은 이미 가족 앨범에 들어와 있는 사람만…” | 이미 누가 앨범을 만들었어요. 그 사람에게 초대 링크를 받으세요. 처음부터 다시 하려면 SQL Editor에서 `delete from families;` 실행 |
| 초대 코드가 맞지 않대요 | 관리자가 초대 코드를 새로 만들었을 수 있어요. 새 링크를 받아 주세요 |
| 앱이 예전 모습 그대로예요 | 앱을 완전히 닫았다 다시 열거나, 브라우저에서 새로 고침 |
| 사진이 안 보여요 (⚠️ 표시) | 인터넷 연결 확인. Supabase 프로젝트가 멈춰 있지 않은지(위 ‘7일’) 확인 |
| 사진이 안 올라가요 (저장공간) | 가족 → ⚙ 설정 → 저장공간 확인 → 오래된 원본 정리, 또는 올릴 때 ‘원본 화질로도 올리기’ 끄기 |
| ‘저장’을 눌렀는데 원본 고르기가 안 나와요 | 그 사진은 원본 없이 올렸거나 원본을 정리한 사진이에요. 화면용(1440px) 사진이 저장돼요 |

## 파일 구조 (코드를 고치고 싶을 때)

```
album/
├─ index.html            앱 첫 페이지
├─ config.js             ★ Supabase 주소·키 넣는 곳
├─ manifest.webmanifest  홈 화면 설치 정보 (이름·아이콘)
├─ sw.js                 오프라인·빠른 열기
├─ css/app.css           디자인 (색은 맨 위 :root 에서 바꿀 수 있어요)
├─ js/
│  ├─ app.js             시작·화면 이동
│  ├─ api-cloud.js       가족 공유 모드 (Supabase)
│  ├─ api-local.js       체험 모드 (이 기기에만 저장)
│  ├─ editor.js          사진 꾸미기 편집기
│  ├─ decor.js           스티커·글자 스티커·테두리 목록 ← 스티커 추가는 여기
│  ├─ filters.js         필터 목록
│  ├─ compose.js         사진 올리기 순서
│  ├─ postcard.js        게시물 카드 (좋아요·댓글·저장)
│  ├─ comments.js        댓글 창 (빠른 댓글 문구는 맨 위 QUICK_REPLIES)
│  ├─ viewer.js          사진 크게 보기
│  └─ screens/           홈·모아보기·소식·가족·처음 화면
├─ vendor/supabase.js    Supabase 라이브러리 (그대로 두세요)
└─ supabase/schema.sql   데이터베이스·보안 규칙
```

빌드 도구 없이 순수 HTML·CSS·JavaScript로 만들어서, 파일을 고치고 커밋하면 바로 반영돼요.
컴퓨터에서 미리 보려면 `album` 폴더에서 `python3 -m http.server` 를 실행하고 `http://localhost:8000` 을 여세요.
